
Shell é uma interface que abstrai funções complexas dos [[Sistemas Operacionais]] (as [[System Calls]]) e permite comandos mais simples para o usuário.

Um programa que emula um terminal abstrai e evita erros de segurança antes dos comandos chegarem ao kernel.

Um shell pode ser apresentado como GUI ou CLI.
Um explorador de arquivos, por exemplo, é uma shell GUI para gerenciar arquivos (tarefa essa que poderia ser feita via CLI)

Um shell pode ser customizado, tanto de aparência como em comandos.
É possível criar atalhos, comandos e automações.

### BASH
O "born-again shell" é o shell mais comum em sistemas Linux, que implementa a interface POSIX de comandos do sistema.
